# WISE FACTORY

**A terminal factory game. Mine, automate, research, and publish.**

광물을 캐고, 컨베이어로 옮기고, 생산 라인을 연결해 **논문**까지 만드는 터미널 방치형 게임입니다. WASD로 2D 탑뷰 맵을 돌아다니며 공장을 설계하세요. 중앙 상인이 끊임없이 들어오는 생산물을 골드로 바꿔 줍니다.

**Node.js 20+ · 외부 패키지 의존성 없음 · 로그인 없이 로컬 플레이**

## 빠른 시작

[Node.js 20 이상](https://nodejs.org/)과 Git을 설치한 뒤 터미널에서 실행하세요.

```sh
git clone https://github.com/slowlytoyou/wise-factory.git
cd wise-factory
npm start
```

`npm install`은 필요하지 않습니다. 첫 실행에는 기본 채굴 라인과 300골드로 시작하며, 이후에는 이 기기에 저장된 공장을 이어서 엽니다.

완성된 생산 라인을 먼저 둘러보려면:

```sh
npm run demo
```

데모에서는 직접 이동·설치·강화할 수 있습니다. 개인 저장 파일을 읽거나 변경하지 않습니다.

터미널은 **120열 × 40행**을 권장하며 최소 **88열 × 30행**이 필요합니다. UTF-8과 한글을 지원하는 고정폭 글꼴을 사용하세요. 작은 화면에서는 카메라가 플레이어를 따라갑니다.

## 무엇을 만들 수 있나요?

- **움직이는 공장:** 41×29 맵, 24 FPS 애니메이션, 실제 물건이 이동하는 컨베이어. 출구가 막히면 생산물이 쌓이고 기다립니다.
- **25가지 품목 · 18가지 제작법:** 철·구리·돌·석탄·원목·석영·금을 채취하고, 금속 부품과 연구 생산물을 조합합니다.
- **상인과 탐사:** 설계도를 구매해 용광로·조립기를 해금하고, 레이더로 새로운 자원을 발견합니다. 판매 전송기로 원하는 곳에 판매 지점을 설치할 수 있습니다.
- **성장과 환생:** 설비를 Lv.5까지 강화하고, 환생으로 **OH 코어**를 얻습니다. 코어 하나마다 모든 판매가에 기본 가격의 25%가 영구 추가되며 소모되지 않습니다.
- **방치형 진행:** 다시 접속하면 최대 8시간의 오프라인 생산을 계산합니다. 로컬 저장은 자동으로 처리됩니다.
- **선택적 클라우드:** 소셜 로그인, 기기 간 저장, 닉네임, 월간 리더보드를 지원합니다. 별도의 Supabase 설정이 필요합니다.

최상위 생산물 **논문**은 `실험데이터 2 + 종이 3 + 반도체 1`로 제작하며 기본 판매가는 **6,000골드**입니다.

```text
원목 → 펄프 → 종이 ──────────────────────────────┐
석영 → 실리콘 ─┐                               │
금광석 → 금괴 ─┼→ 반도체 ─┐                      │
금속 → 회로 ──┘          ├→ 연구장비 → 실험데이터 ┼→ 논문
금속 → 엔진 ─────────────┤                      │
유리·전선·회로 → 센서 ───┘                      │
반도체 ─────────────────────────────────────────┘
```

위 흐름은 주요 생산 경로를 보여 줍니다. 정확한 재료와 수량은 게임에서 `C`를 누르거나 [전체 제작법](docs/GAMEPLAY.md#생산과-판매)을 확인하세요.

## 처음 5분

1. `WASD`로 `@`를 움직이고, 철이나 돌 광맥 위에서 `1` → `E`로 채굴기를 설치합니다.
2. `2`로 벨트를 선택하고 `R`로 방향을 맞춰 중앙 상인의 3×3 구역까지 연결합니다.
3. 상인 근처에서 `B`를 열어 용광로 설계도와 구리 레이더를 구입합니다.
4. `3`으로 용광로를 설치하고 `F`로 제작법을 선택합니다. 재료를 공급하면 자동으로 가공합니다.
5. `U`로 설비를 강화하고, 조립기를 해금해 더 값비싼 제품을 만듭니다.

이번 회차 판매액이 5,000골드에 도달하면 `T`에서 환생 보상과 초기화 범위를 확인할 수 있습니다. [상점·환생·생산 상세 가이드](docs/GAMEPLAY.md)

## 조작

| 키 | 동작 |
| --- | --- |
| `WASD` / 방향키 | 이동 |
| `1` / `2` / `3` / `4` / `5` | 채굴기 / 벨트 / 용광로 / 조립기 / 전송기 선택 |
| `E` / `Space` | 현재 칸에 설치 |
| `R` / `U` / `X` | 회전 / 강화 / 철거 |
| `F` / `C` | 제작법 변경 / 생산 도감 |
| `B` | 상인 근처에서 상점 열기 |
| `T` | 환생 안내와 실행 |
| `N` | 닉네임 설정 |
| `L` | 로컬 기록 또는 클라우드 월간 리더보드 |
| `P` | 일시정지; 클라우드는 화면만 정지 |
| `?` / `Esc` | 도움말 / 열린 창 닫기 |
| `Q` / `Ctrl+C` | 저장하고 종료 |

## 저장과 클라우드

**`npm start`는 항상 로컬 모드입니다.** 회원가입이나 인터넷 연결 없이 채굴·가공·상점·환생을 모두 즐길 수 있습니다. 기본 저장 경로는 `~/.local/state/starfall/factory-v2.json`이며, 10초마다 그리고 종료할 때 저장합니다. `XDG_STATE_HOME`을 지정한 경우 해당 경로를 사용합니다.

다른 로컬 공장을 시작하려면 저장 경로를 지정하세요.

```sh
node src/main.mjs --save ./my-factory.save.json
```

클라우드는 선택 사항입니다. 이 저장소에는 실제 서버 연결 설정이 포함되어 있지 않으므로 **[Supabase 설정 가이드](docs/CLOUD_SETUP.md)**를 먼저 따라 주세요. 서버를 준비한 다음:

```sh
npm run login -- github
npm run cloud
```

같은 서버를 사용하는 플레이어끼리 월간 판매액과 **초당 평균 골드 생산량**을 비교합니다. 리더보드는 **매월 1일 00:00 한국 시간(Asia/Seoul)**에 새 시즌으로 전환되며, 공장·보유 골드·OH 코어는 유지됩니다. 평균 생산량은 서버가 반영한 해당 월 판매액을 생산 시간으로 나눈 값입니다.

로컬과 클라우드는 별도 저장 슬롯입니다. 로그인해도 로컬 공장이 전환되지 않으며 로컬 저장을 클라우드 순위에 가져오지 않습니다. 두 모드의 저장·오프라인 생산·동기화 동작은 [플레이 가이드](docs/GAMEPLAY.md#개인-저장과-선택적-클라우드)에 정리되어 있습니다.

## 개발과 검증

```sh
npm test                 # 시뮬레이션·저장·UI·클라우드 단위 테스트
npm run test:pty          # 실제 터미널 입력 흐름 검증
npm run test:cloud-pty    # 가짜 클라우드 서버를 사용하는 터미널 검증
npm run snapshot         # 새 공장의 정적 화면 출력
```

PTY 검증에는 macOS/Linux와 Python 3이 필요합니다. OAuth 테스트는 로컬 루프백 서버와 가짜 응답을 사용하며 실제 계정이 필요하지 않습니다.

| 경로 | 역할 |
| --- | --- |
| `src/main.mjs` | 실행 옵션·키 입력·게임 루프 |
| `src/factory-render.mjs` | 탑뷰 맵·애니메이션·게임 UI |
| `supabase/functions/_shared/factory.mjs` | 로컬과 서버가 공유하는 공장 시뮬레이션 |
| `src/factory-save.mjs` | 로컬 저장과 복원 |
| `src/cloud.mjs`, `src/cloud-game.mjs` | 로그인·서버 통신·동기화 |
| `supabase/functions/`, `supabase/migrations/` | 클라우드 API·리더보드·데이터베이스 |
