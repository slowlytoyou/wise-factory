# WISE FACTORY

**A terminal factory game. Mine, automate, research, and publish.**

광물을 캐고, 컨베이어로 옮기고, 생산 라인을 연결해 **논문**까지 만드는 터미널 방치형 게임입니다. WASD로 2D 탑뷰 맵을 돌아다니며 공장을 설계하세요. 중앙 상인이 끊임없이 들어오는 생산물을 골드로 바꿔 줍니다.

**Node.js 20+ · 외부 패키지 의존성 없음 · 로그인 없이 로컬 플레이**

## 빠른 시작

[Node.js 20 이상](https://nodejs.org/)과 Git을 설치한 뒤 터미널에서 실행하세요.

```sh
git clone https://github.com/slowlytoyou/wise-factory.git
cd wise-factory
npm start
```

`npm install`은 필요하지 않습니다. 첫 실행에는 기본 채굴 라인과 300골드로 시작하며, 이후에는 이 기기에 저장된 공장을 이어서 엽니다.

완성된 생산 라인을 먼저 둘러보려면:

```sh
npm run demo
```

데모에서는 직접 이동·설치·강화할 수 있습니다. 개인 저장 파일을 읽거나 변경하지 않습니다.

터미널은 **120열 × 40행**을 권장하며 최소 **88열 × 30행**이 필요합니다. UTF-8과 한글을 지원하는 고정폭 글꼴을 사용하세요. 작은 화면에서는 카메라가 플레이어를 따라갑니다.

## 무엇을 만들 수 있나요?

- **움직이는 공장:** 41×29 맵, 24 FPS 애니메이션, 실제 물건이 이동하는 컨베이어. 출구가 막히면 생산물이 쌓이고 기다립니다.
- **25가지 품목 · 18가지 제작법:** 철·구리·돌·석탄·원목·석영·금을 채취하고, 금속 부품과 연구 생산물을 조합합니다.
- **상인과 탐사:** 설계도를 구매해 용광로·조립기를 해금하고, 레이더로 새로운 자원을 발견합니다. 판매 전송기로 원하는 곳에 판매 지점을 설치할 수 있습니다.
- **성장과 환생:** 설비를 Lv.5까지 강화하고, 환생으로 **OH 코어**를 얻습니다. 코어 하나마다 모든 판매가에 기본 가격의 25%가 영구 추가되며 소모되지 않습니다.
- **방치형 진행:** 게임을 켜 둔 동안 자동으로 생산하고 저장합니다. 종료하거나 컴퓨터가 잠든 동안의 추가 보상은 없습니다.
- **선택적 클라우드:** GitHub 로그인, 기기 간 저장, 닉네임, 월간 리더보드를 지원합니다. 공유 서버 연결 설정이 포함되어 있어 바로 로그인할 수 있습니다.

최상위 생산물 **논문**은 `실험데이터 2 + 종이 3 + 반도체 1`로 제작하며 기본 판매가는 **6,000골드**입니다.

```text
원목 → 펄프 → 종이 ──────────────────────────────┐
석영 → 실리콘 ─┐                               │
금광석 → 금괴 ─┼→ 반도체 ─┐                      │
금속 → 회로 ──┘          ├→ 연구장비 → 실험데이터 ┼→ 논문
금속 → 엔진 ─────────────┤                      │
유리·전선·회로 → 센서 ───┘                      │
반도체 ─────────────────────────────────────────┘
```

위 흐름은 주요 생산 경로를 보여 줍니다. 정확한 재료와 수량은 게임에서 `C`를 누르거나 [전체 제작법](docs/GAMEPLAY.md#생산과-판매)을 확인하세요.

## 처음 5분

1. `WASD`로 `@`를 움직이고, 철이나 돌 광맥 위에서 `1` → `E`로 채굴기를 설치합니다.
2. `2`로 벨트를 선택하고 `R`로 방향을 맞춰 중앙 상인의 3×3 구역까지 연결합니다.
3. 상인 근처에서 `B`를 열어 용광로 설계도와 구리 레이더를 구입합니다.
4. `3`으로 용광로를 설치하고 `F`로 제작법을 선택합니다. 재료를 공급하면 자동으로 가공합니다.
5. `U`로 설비를 강화하고, 조립기를 해금해 더 값비싼 제품을 만듭니다.

이번 회차 누적 판매액이 5,000골드에 도달하면 환생으로 OH 코어를 받습니다. 판매액 5,000에서 +1개, 20,000에서 +2개, 45,000에서 +3개로 늘어나며, 보유 골드가 아니라 실제 판매한 총액을 기준으로 하므로 건설·구매에 돈을 써도 보상이 줄지 않습니다. `T`에서 받을 코어와 초기화 범위를 확인하세요. [상점·환생·생산 상세 가이드](docs/GAMEPLAY.md#환생)

## 조작

| 키 | 동작 |
| --- | --- |
| `WASD` / 방향키 | 이동 |
| `1` / `2` / `3` / `4` / `5` | 채굴기 / 벨트 / 용광로 / 조립기 / 전송기 선택 |
| `E` / `Space` | 현재 칸에 설치 |
| `R` / `U` / `X` | 회전 / 강화 / 철거 |
| `F` / `C` | 제작법 변경 / 생산 도감 |
| `B` | 상인 근처에서 상점 열기 |
| `T` | 환생 안내와 실행 |
| `N` | 닉네임 설정 |
| `K` | Original / Work / Work Dev 스킨 선택 |
| `L` | 로컬 기록 또는 클라우드 월간 리더보드 |
| `P` | 일시정지; 클라우드는 화면만 정지 |
| `?` / `Esc` | 도움말 / 열린 창 닫기 |
| `Q` / `Ctrl+C` | 저장하고 종료 |

**한글 두벌식 입력 상태에서도 단축키를 사용할 수 있습니다.** `ㅈㅁㄴㅇ`은 `WASD`, `ㄷ`은 설치(`E`), `ㅕ`는 강화(`U`), `ㅂ`은 종료(`Q`)로 동작합니다. 닉네임 입력창에서는 한글을 그대로 입력합니다.

## 스킨

게임 중 **`K`**를 눌러 스킨을 선택합니다. `W/S`·방향키 또는 `1/2/3`으로 선택하고 `Enter`로 적용합니다. `Esc`로 닫으면 기존 스킨을 유지합니다.

| 스킨 | 화면 | 표시 용어 |
| --- | --- | --- |
| **Original Skin** | 기존 색상·광맥·풍부한 애니메이션 | 게임 용어 |
| **Work Skin** | 차분한 색상, 격자와 노드로 구성한 업무 대시보드 | 게임 용어 유지 |
| **Work Skin · Dev** | Work Skin과 같은 업무 대시보드 | 프로그래밍 용어 |

Dev 스킨에서는 채굴기를 **수집기**, 용광로를 **빌드 워커**, 조립기를 **통합 워커**, 환생을 **리팩터링**, 논문을 **기술 백서**로 표시합니다. 닉네임은 입력한 그대로 보이며, 스킨 선택은 화면 설정으로만 적용됩니다.

```sh
npm run work              # Work Skin · 게임 용어 유지
npm run work:dev          # Work Skin · 프로그래밍 용어
npm start -- --skin original
npm run demo -- --skin work-dev
```

일반 플레이에서 `K`로 적용한 스킨은 이 기기에 저장되어 다음 실행과 로컬·클라우드 모드에 공통 적용됩니다. 실행 옵션 `--skin original|work|work-dev`는 해당 실행에만 적용됩니다. 데모와 스냅샷은 스킨 설정 파일을 읽거나 변경하지 않습니다.

## 저장과 클라우드

**`npm start`는 항상 로컬 모드입니다.** 회원가입이나 인터넷 연결 없이 채굴·가공·상점·환생을 모두 즐길 수 있습니다. 기본 저장 경로는 `~/.local/state/starfall/factory-v2.json`이며, 10초마다 그리고 종료할 때 저장합니다. `XDG_STATE_HOME`을 지정한 경우 해당 경로를 사용합니다.

다른 로컬 공장을 시작하려면 저장 경로를 지정하세요.

```sh
node src/main.mjs --save ./my-factory.save.json
```

클라우드는 선택 사항입니다. **공유 서버 연결 설정이 포함되어 있으므로 Supabase 계정이나 별도 설정 없이** 본인의 GitHub 계정으로 로그인하면 됩니다. 이미 내려받은 저장소라면 먼저 최신 버전으로 업데이트하세요.

```sh
git pull
npm run login -- github
npm run cloud
```

브라우저에서 로그인하고 처음 클라우드 게임을 열면 본인 전용 공장이 생성됩니다. 다른 기기에서도 같은 GitHub 계정으로 로그인하면 이어서 플레이합니다. 서버 연결 설정만 공유하며, 로그인 세션과 공장은 계정마다 분리됩니다.

같은 서버를 사용하는 플레이어끼리 월간 판매액과 **최근 60초 골드/초**, **총 플레이 시간**을 비교합니다. 골드/초는 **최근 60초 동안 실제로 판매한 금액 ÷ 60**이며, 클라우드 저장과 열어 둔 리더보드는 약 **3초마다** 갱신됩니다. 예를 들어 최근 60초에 120골드를 판매했다면 2골드/초입니다. 업그레이드 비용은 판매액에서 빼지 않으며, 판매가 멈추면 기존 판매가 60초 구간에서 빠지면서 수치도 내려갑니다. 최근 판매 기록은 이 업데이트 이후부터 쌓입니다.

순위는 **월간 판매액** 기준입니다. 월간 점수는 **매월 1일 00:00 한국 시간(Asia/Seoul)**에 초기화되며, 최근 60초 골드/초·공장·보유 골드·OH 코어·총 플레이 시간은 월 전환으로 초기화되지 않습니다. 총 플레이 시간은 이 기능 업데이트 이후 게임이 실행되고 서버에 연결된 시간을 누적하며, 환생해도 유지됩니다.

로컬과 클라우드는 별도 저장 슬롯입니다. 로그인해도 로컬 공장이 전환되지 않으며 로컬 저장을 클라우드 순위에 가져오지 않습니다. 두 모드의 저장·생산·동기화 동작은 [플레이 가이드](docs/GAMEPLAY.md#개인-저장과-선택적-클라우드)에 정리되어 있습니다.

## 개발과 검증

```sh
npm test                 # 시뮬레이션·저장·UI·클라우드 단위 테스트
npm run test:pty          # 실제 터미널 입력 흐름 검증
npm run test:cloud-pty    # 가짜 클라우드 서버를 사용하는 터미널 검증
npm run snapshot         # 새 공장의 정적 화면 출력
```

PTY 검증에는 macOS/Linux와 Python 3이 필요합니다. OAuth 테스트는 로컬 루프백 서버와 가짜 응답을 사용하며 실제 계정이 필요하지 않습니다.

| 경로 | 역할 |
| --- | --- |
| `src/main.mjs` | 실행 옵션·키 입력·게임 루프 |
| `src/factory-render.mjs` | 탑뷰 맵·애니메이션·게임 UI |
| `supabase/functions/_shared/factory.mjs` | 로컬과 서버가 공유하는 공장 시뮬레이션 |
| `src/factory-save.mjs` | 로컬 저장과 복원 |
| `src/cloud.mjs`, `src/cloud-game.mjs` | 로그인·서버 통신·동기화 |
| `supabase/functions/`, `supabase/migrations/` | 클라우드 API·리더보드·데이터베이스 |
