# ✦ STARFALL · 별빛 공방

터미널 속 작은 우주 공방을 키우는 방치형 게임입니다. 유성에서 별가루를 모으고, 다섯 종류의 설비를 늘려 새로운 별자리로 승천하세요.

외부 패키지, 계정, 네트워크 연결 없이 Node.js 표준 라이브러리만 사용합니다.

## 시작하기

Node.js 20 이상이 필요합니다. 이 프로젝트 폴더에서 실행하세요. `npm install`은 필요하지 않습니다.

```sh
npm run classic
```

처음부터 모든 설비의 애니메이션을 보고 싶다면:

```sh
npm run classic -- --demo
```

데모에서는 저장 파일을 읽거나 쓰지 않습니다. 구매와 수집도 직접 체험할 수 있습니다.

터미널은 **110열 × 38행 이상**을 권장합니다. 최소 크기는 88열 × 32행이며, 더 작은 창에서도 생산은 계속되고 크기 안내가 표시됩니다. UTF-8과 한글 표시가 가능한 고정폭 글꼴을 사용하세요. 색상은 ANSI 트루컬러로 출력합니다.

## 움직이는 공방

- 서로 다른 주기로 반짝이는 별, 꼬리를 남기는 유성, 음영이 있는 달
- 위아래로 떠 있는 수정섬과 궤도를 도는 채집 드론
- 깜빡이는 채굴 광선, 흘러내리는 별가루, 이동하는 컨베이어
- 설비별 증기, 정제소의 불꽃, 회전하는 관측소
- 직접 수집하거나 설비를 구매할 때 퍼지는 입자와 보상 표시

기본 24 FPS이며 변경된 화면 행만 다시 그립니다. 게임 생산량은 프레임 속도와 독립적으로 계산됩니다.

## 조작

| 키 | 동작 |
| --- | --- |
| `1`–`5` | 해당 설비 구매·강화 |
| `Space` | 별빛 수집, 1.5초 충전 |
| `A` | 자동 구매 켜기·끄기, 누적 별가루 500개부터 해금 |
| `R` | 승천, 이번 회차 생산 25,000개부터 가능 |
| `Y` / `N` | 승천 확인 / 취소 |
| `P` | 게임과 애니메이션 일시 정지·재개 |
| `?` / `H` | 도움말 |
| `Esc` | 도움말 닫기·승천 취소 |
| `Q` / `Ctrl+C` | 저장하고 종료 |

처음에는 별가루 25개와 초당 0.35개의 기본 생산량을 받습니다. `1`로 첫 드론을 구매하면 생산량이 올라갑니다. 자동 구매는 켜 두면 5초마다 구매 가능한 설비 중 비용 대비 생산량이 높은 설비를 하나 구매합니다.

승천하면 현재 자원과 설비가 초기화되고 영구 생산 배율이 0.5씩 증가합니다. 누적 생산량과 업적은 유지됩니다. 수집 보상도 생산량에 따라 증가합니다.

## 저장

10초마다, 그리고 정상 종료할 때 저장합니다. 기본 위치는:

```text
~/.local/state/starfall/save.json
```

`XDG_STATE_HOME`이 절대 경로로 설정되어 있으면 그 아래의 `starfall/save.json`을 사용합니다. 게임이 실행되는 동안에만 생산합니다. 종료·컴퓨터 절전·일시 정지 동안에는 추가 보상이 없으며, 다시 실행하면 저장한 상태에서 이어 갑니다.

저장 파일은 같은 폴더에 임시 파일을 작성한 뒤 교체합니다. 손상된 JSON이나 미지원 버전의 저장 파일은 보존하고, 화면에 저장 불가 상태를 표시합니다. 새 게임이나 별도 슬롯은 저장 경로를 바꾸어 시작할 수 있습니다. 같은 저장 파일로 여러 게임을 동시에 실행하면 마지막 저장이 남으므로 슬롯을 나누어 주세요.

```sh
node src/classic.mjs --save ./my-workshop.save.json
```

## 실행 옵션과 검증

```sh
node src/classic.mjs --fps 30       # 10–60 FPS
node src/classic.mjs --no-color     # 색상 없이 실행
node src/classic.mjs --help
npm run classic -- --snapshot      # 실행 없이 텍스트 화면 확인
node src/classic.mjs --demo --snapshot
npm test
python3 scripts/classic-pty-smoke.py # macOS/Linux + Python 3: 실제 PTY 입출력 검증
```

`NO_COLOR` 환경 변수도 지원합니다. 스냅샷과 데모는 기존 진행에 영향을 주지 않습니다.

## 코드 구조

| 파일 | 역할 |
| --- | --- |
| `src/classic.mjs` | 실행 옵션, 키 입력, 게임 루프, 종료 처리 |
| `src/model.mjs` | 생산, 설비, 자동 구매, 업적, 승천, 저장 상태 복원 |
| `src/render.mjs` | 장면 애니메이션과 게임 화면 |
| `src/terminal.mjs` | 한글·유니코드 너비 처리와 ANSI 화면 버퍼 |
| `src/save.mjs` | 저장 파일 읽기와 원자적 저장 |

자동 테스트는 임시 폴더를 사용하며 실제 게임 저장 파일에 접근하지 않습니다.

PTY 검증은 키 입력, 창 크기 변경, 종료 후 터미널 복원, 중단·재개, 손상된 저장 파일 보존을 확인합니다. Python은 이 선택적 개발 검증에만 사용하고 게임 실행에는 필요하지 않습니다.
